# Contribuir

Las propuestas deben ayudar a mantener el proyecto claro, acotado y verificable.

## Antes de abrir un pull request

- Para cambios grandes o que alteren el comportamiento, abre primero una
  discusión o un issue para acordar el alcance.
- Comprueba que el cambio corresponde a este repositorio y no introduce
  dependencias, cambios de publicación ni modificaciones de derechos que no
  hayan sido acordados.
- No incluyas secretos, datos personales ni materiales de terceros sin permiso
  documentado.

## Pull requests

Describe el problema y la solución, enumera los archivos o superficies
afectados e indica las comprobaciones realizadas. Si no ejecutaste una prueba,
indícalo. Incluye capturas cuando ayuden a revisar un cambio visual.

Mantén cada propuesta enfocada y conserva los comportamientos existentes que no
formen parte del alcance acordado. No publiques ni despliegues cambios como
parte de una contribución.

## Derechos sobre las contribuciones

Los derechos sobre una contribución permanecen con sus titulares. Enviar un
pull request no convierte el repositorio en contenido de libre reutilización ni
otorga al público una licencia sobre el proyecto. Antes de integrar una
contribución, los mantenedores deben confirmar que cuentan con permiso para
incluirla y mantenerla en este proyecto. No envíes contenido cuya autorización
no puedas confirmar.
