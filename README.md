# Trivias

Aplicación web estática hecha con HTML, CSS y JavaScript; no utiliza un framework de aplicación. El `package.json` declara actualmente `csv-parse` como herramienta auxiliar. Esa herramienta no cambia la naturaleza estática del sitio.

[Visitar Trivias](https://trivias.lluviadeideas-juegosdidacticos.com/)
