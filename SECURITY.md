# Política de seguridad

## Comunicación privada

No publiques vulnerabilidades, datos sensibles ni instrucciones de explotación
en issues, discusiones o pull requests públicos.

Si GitHub ofrece la opción **Report a vulnerability** para este repositorio,
utilízala para enviar un informe privado. Si esa opción no está disponible,
contacta en privado a los mantenedores a través de la organización
[lluviadeideas-juegosdidacticos](https://github.com/lluviadeideas-juegosdidacticos).
No incluyas secretos, datos personales ni información de terceros que no sea
necesaria para explicar el problema.

## Qué incluir

Incluye una descripción clara del impacto, los pasos mínimos para reproducir el
problema y las versiones o rutas afectadas. No realices pruebas que accedan,
modifiquen o interrumpan datos o servicios de terceros.

Los mantenedores revisarán el informe y coordinarán los siguientes pasos por el
mismo canal privado. No se garantiza un plazo de respuesta ni una fecha de
corrección.

## Alcance

Esta política cubre el código y los materiales mantenidos en este repositorio.
La disponibilidad pública del repositorio no constituye autorización para
acceder a sistemas ajenos, degradar servicios ni divulgar información
confidencial.
